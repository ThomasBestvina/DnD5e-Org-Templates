# HOW TO USE
# 1. Copy this file and fill in the cells
# 2. Edit only: ability scores (not mod), Level, proficiency markers (1 / 2), items, coins.
# 3. Most other things are calculated. Some exceptions to things with many modifiers that may inhibit play if precalculated, e.g. AC.
# Recalculate the whole buffer with M-x org-table-recalculate-buffer-tables I highly recommend setting this to a bind as you will use it frequently.
#    (or press C-u C-c * to recalc that table).
# Passive perception requires two buffer recalculations to be correct upon changing wisdom.
# 4. Proficiency column: leave blank = none, 1 = proficient, 2 = expertise, 3.. if rules allow.
# Tips:
# Olivetti mode and text wrapping can sometimes break the tables, especially spells. If for some reason you find this desirable, remove the top line.
# To make navigation less clunky, you should keep frames open to different parts of the sheet you're interested in. org-tree-to-indirect-buffer opens a
# subtree at a point (C-c C-x b). You can save layouts with C-x r w 'x', and restore with C-x r j 'x'. x = any character as a register.
# e.g. have a layout for combat, layout for non-combat, etc.
# Editing the table math can be extremely error prone, for homebrew rules that changed these calculations, it's often easier to just delete parts of a calculation and do it yourself,
# @x$y is row, column (starting at 1), and :: seperates calculations.

# This template can be used perfectly well for single classing, but the class calculations are extra work and difficult to understand when you just want to single class.
